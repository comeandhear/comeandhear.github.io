Privacy Policy

Come and Hear publishing tools · effective November 6, 2026

This policy covers the private production tools of the YouTube channel Come and Hear (the "tools"). Using the tools means agreeing to this policy.

YouTube API Services

The tools use YouTube API Services (the YouTube Data API, the YouTube Analytics API and the YouTube Reporting API). By using the tools you agree to be bound by the YouTube Terms of Service. The Google Privacy Policy applies to the data Google handles.

Who uses the tools

Only the owner of the Come and Hear channel. The tools are not offered to the public and no other person signs in to them.

What data the tools access

With the owner's authorization through Google sign-in, the tools access, for the Come and Hear channel only:

  • the channel's videos, playlists, captions, thumbnails and comments, and their titles, descriptions, tags and translations (YouTube Data API), to publish and update them;
  • the channel's aggregated statistics, such as views, watch time, audience retention, thumbnail impressions and click-through rate (YouTube Analytics and Reporting APIs), to plan new videos.

To research topics for new videos, the tools also run YouTube searches and read public information about the videos found: title, channel name, thumbnail, public view count and duration, shown as YouTube returns them, without any metric calculated from them. The tools do not collect personal information about viewers, commenters or any other YouTube user.

How the data is used and shared

The data is used only to produce and manage the channel's own videos. The owner may use AI assistants (Anthropic's Claude) to help read the channel's statistics and research results; they process the data only to assist the owner. Nothing is sold, shared with other parties or used for advertising. The tools do not allow third parties to serve content or advertisements.

How the data is stored

  • The authorization token is stored in a file readable only by the owner, on the owner's private server.
  • The channel's own statistics are kept in the owner's private project records for as long as they are needed to plan the channel's videos. The tools use the authorization every few days, which confirms at least every 30 days that it is still valid.
  • Search results about other channels' videos (titles, channel names, thumbnails and public counts) are kept for 30 days at most and then deleted automatically.
  • The tools are command-line programs: they place no cookies or similar technology on anyone's device. This website uses no cookies and no analytics.

Revoking access and deleting data

Access can be revoked at any time on the Google security settings page, myaccount.google.com/permissions. After a revocation, the stored token and the data obtained through the YouTube API Services are deleted within 30 days. A request to delete stored data, sent to the contact below, is fulfilled within 7 days.
